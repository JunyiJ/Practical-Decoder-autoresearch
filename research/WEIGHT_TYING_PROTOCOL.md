## Intervention and controls

Three families receive the same bounded LR tuning: `legacy_untied`, `matched_untied`, and `scaled_tied`. The explicit policy is `mha4_scaled_table_sharing`, restricted to dense four-layer MHA, head dimension32, bias-free SwiGLU hidden dimension21D/8, RMS block norms, RoPE, unscaled residuals, base width64, widths64/128/256, and the explicit inherited input-scale, final-normalization and training-bound output-bias contracts. No generic tying flag, manual readout multiplier or initialization override is accepted.

Legacy preserves the existing constructor and forward arithmetic: unit-normal embedding E, independent muP-adjusted uniform readout W, and logits hWᵀ/width_mult+b. All families first execute this complete legacy construction, including the readout RNG draws. Matched then copies E into the existing separate readout parameter Q without drawing RNG. It computes k hQᵀ/width_mult+b. Tied removes the registered readout and computes the same expression functionally with E, with one canonical `transformer.wte.weight` entry. Both use fixed k=1/sqrt(192); the output bias remains after the width division.

Actual CPU tests verify matched and tied initial functions, shared non-table weights and RNG. The tied lookup/output gradients sum into one table gradient, with one AdamW base-rate parameter group, state, independent-decay application and H200 shadow. MPS verification remains a separate required gate. The hidden Muon width factor remains1/sqrt(D/64). Checkpoint loading rejects changed kinds, config deletion, fixed-scale mutation and noncanonical head/table layouts. Derived inference checkpoints retain one canonical shared table and cannot resume an optimizer.

The matched control changes readout distribution, input/output correlation, and optimizer coordinates relative to legacy. Tying additionally couples parameter gradients and adaptive histories. Equal initial function does not imply equal subsequent trajectories, optimal muP transfer, an isolated parameter-count effect or a local quality gain. At vocabulary65, removal of V×D parameters is calculated as4160/16640 at widths64/256; these are not measured savings or speedups.
